## November 3, 2026

**Demo and landing page**
- New public [demo campaign](/demo): a real brief, 7 ranked YouTube creators and sample outreach pitches. No sign-in needed.
- Temporary landing page with sign-up, log-in, the demo and these docs.

**Docs**
- New docs at `/docs`, linked from the app's top bar.

**Fixes**
- Fixed the pitch export: Instagram, Twitter and Status columns were empty. LinkedIn is now included.

**Behind the scenes** (rolls out with the next discovery update)
- A new discovery engine, now in testing: platforms are searched in parallel, it searches again when too few creators qualify, interrupted runs pick up where they stopped, and each creator's reason agrees with its label. See [How it works](/docs/how-it-works).
- Backup AI models, so a run can switch provider if one is down.
- Cost tracking for every AI call.
- A shared cache, so repeated searches will be faster and cheaper.

## Earlier
