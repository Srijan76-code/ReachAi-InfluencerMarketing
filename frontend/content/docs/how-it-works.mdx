## Cheap work first, expensive work last

Every campaign runs as a pipeline. Each step narrows the list before a more expensive step runs:

| Step | Who does it | What happens |
|---|---|---|
| Understand the brief | Language model (1 call, reused for the same brief) | Topics, audience problems, formats and short search terms |
| Choose platforms | Your business type + a quick AI check | Which platforms fit your product |
| Find candidates | Platform API + creators we already know | Several searches at once; creators that several searches agree on come first |
| Filter and measure | Code | Size, country, activity, views, reliability, engagement |
| Shortlist | Semantic search | Keep the creators whose content is closest to your brief |
| Judge fit | [Jev](https://docs.typesafe.ai/introduction), one request per creator | Topic and audience fit, the audience's problems, brand safety, real person or not |
| Score | Code | Fit + health − risk → final score, fair price, forecast |
| Explain | Language model | One-line reason, only for the creators you'll contact |

## Fast and cheap

- **Platforms are searched in parallel.** Platforms that suit your brief get a full search. Others get a small test search first, and a full search only if they find creators who beat your current list.
- **A second search when too few creators qualify.** If too few creators pass your size, country and activity checks, it searches once more.
- **Every candidate gets a cheap size and country check** before anything expensive, so the costly steps only run on creators that can actually work for you.
- **Repeat runs are faster.** Briefs, searches, judgments and creator data are remembered, so a similar campaign runs quicker and cheaper.

A typical run takes **10–30 seconds** and costs well under one cent in AI calls.

## Judgments by Jev, words by language models

Most AI work in creator discovery is judging, not writing: *is this a real person? does the audience match? is it brand-safe?* These judgments go to **Jev**, a fast model built for yes/no, label and scale questions. It answers all of a creator's questions in one request and gives probabilities, so thresholds mean something and can be tuned.

Language models only write the text you read: the strategy, the reasons and the pitches. Numbers like views, growth and fair price always stay in code.

## Reliability

- Runs happen in the background; you can close the page.
- **Picks up where it stopped.** If a run is interrupted, the retry continues from the last finished step instead of starting over.
- Starting a campaign again cancels the run still going, so you never get two lists mixed up.
- Backup AI models take over if a provider is down, and every paid call is tracked.
