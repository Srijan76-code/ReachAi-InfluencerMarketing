title: Use ReachAI from your agent
description: Connect Claude Code, Cursor or any MCP agent to ReachAI and work with your campaigns and creators from there.
---

ReachAI runs an [MCP](https://modelcontextprotocol.io) server. Once your agent is connected, you can ask it things like "which of my campaigns have finished?" or "show me the top 10 creators for the DataLaunch campaign" without opening the app. Anything your agent saves shows up in ReachAI straight away, because it is the same account and the same data.

## Connect

1. Open [Agents](/agents) in the app and create a key. Copy it right away: it is shown only once.
2. Add ReachAI to your agent with the command the page gives you.

**Claude Code**

```bash
claude mcp add --transport http reachai https://YOUR-REACHAI-HOST/api/mcp --header "Authorization: Bearer YOUR_KEY"
```

**Cursor** (`mcp.json`)

```json
{
  "mcpServers": {
    "reachai": {
      "url": "https://YOUR-REACHAI-HOST/api/mcp",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}
```

Other agents that support MCP over HTTP with a custom header work the same way: use the address and the `Authorization: Bearer` header.

Keys belong to you. Anyone with a key can see and change your campaigns, so keep it private. You can revoke a key on the [Agents](/agents) page at any time, and it stops working immediately.

## Easiest setup

Tell your agent: "set up ReachAI from https://YOUR-REACHAI-HOST/llms.txt". It reads the instructions, asks you for a key and connects itself. There is also a playbook at `/skill.md` that teaches the agent how to use ReachAI well.

## What your agent can do

| Ask for | What it does |
|---|---|
| Your campaigns | Lists them with status and number of creators found |
| A campaign's details | Shows the brief and where the search is up to |
| A new campaign | Creates one from a short brief. It does **not** start the search |
| A creator search | Starts it, but only after your agent has told you and you agreed. Searches use your YouTube quota and AI credits, so each person's agents can start 3 a day |
| Search progress | Tells you whether the search has finished |
| The creators | A ranked table with score, audience, engagement and estimated fair value, with sorting, a minimum score and pages |
| One creator | Full numbers, score breakdown, recent videos and why they fit |
| Saved creators | Lists, saves or removes creators on the campaign's shortlist (the same list as the Saved tab) |
| A first message | Your agent writes it in your voice; ReachAI checks it (no price above the creator's fair range, no placeholders, no internal terms) and saves it as a **draft in that creator's chat**. You review and send it in ReachAI |
| What needs you | Who replied, which drafts are waiting, where each deal stands, and the Track results: spend, views, signups or sales, late posts and who is due payment |

Scores, audience sizes, prices and results are calculated by ReachAI, not by your agent, so they match what you see in the app. The agent only lays them out.

If your agent's client supports slash commands, you also get `/reachai-new-campaign`, `/reachai-draft-pitches` and `/reachai-check-inbox`.

## What it can't do

- Send anything. Drafts are saved for you to send, and nothing your agent does can send a message or move money.
- Agree terms, set prices or mark a creator paid. Those stay in the app.
- Reply to a creator. When a creator writes back, the chat in ReachAI suggests the next reply.

## A note on safety

Creator names, bios and summaries come from the internet. ReachAI marks them as untrusted when it hands them to your agent, so a creator can't tell your agent what to do. If your agent also has tools that send email or spend money, keep those on "ask me first".
